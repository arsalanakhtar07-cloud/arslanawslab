💡 Clear answers

AWS deployment FAQ

Quick answers for anyone learning how this project works.

What is Arslan AWS Lab?+

Arslan AWS Lab is a beginner-friendly static website project that demonstrates an automatic deployment from GitHub to AWS.

How does a GitHub update reach the live website?+

A push to the main branch starts GitHub Actions. The workflow builds the site, uploads it to a private S3 bucket, and invalidates the CloudFront cache.

Are AWS access keys stored in GitHub?+

No. GitHub Actions uses OIDC to request short-lived AWS credentials for a tightly limited IAM role.

Why use CloudFront in front of S3?+

CloudFront provides HTTPS, edge caching, a public URL, and controlled access to the private S3 origin.
